# Project 3 — Multiband LEO Propagation Modeling

## Objective

Extend the propagation model across S-, C-, and X-band
LEO communication scenarios.

## Inputs

- Elevation
- Slant range
- Carrier frequency
- Rain rate
- Relative humidity
- Temperature
- Time

## ML model

Random Forest regression

## Outputs

- Predicted excess path loss
- Prediction error
- Feature importance
- Cross-band comparison

## System relevance

The model provides propagation information that can support
adaptive modulation/coding and frequency-selection decisions.
